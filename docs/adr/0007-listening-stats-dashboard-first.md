# ADR-0007：听歌时长统计与大屏主导（产品定位调整）

- 状态：已接受（用户于 2026-11-07 提出需求并要求继续实施）
- 日期：2026-11-07
- 关联：ADR-0005（模块协议）、ADR-0006（网易云账号接入）、AGENTS.md §4/§5

## 1. 决策一：听歌时长如何记录

**心跳累加（选定）**：播放器在真实播放期间累计实际秒数，每满 30 秒
POST `listeningHeartbeat {songId, title, artist, seconds≤120, first}`；
切歌、暂停、pagehide、组件卸载时先冲账零头。

- 服务端按 **(workspace, user, day, song)** 唯一键 upsert 累加到
  `modules.dashboard.listening_daily`（seconds/plays 累加，userName 为会话快照）。
- 否决"开始/结束会话事件"：崩溃/关标签页丢整段数据，心跳最多丢一个周期。
- **遥测不进审计日志**：心跳是高频遥测写入，逐条审计会淹没审计流；
  宪法"所有写操作可审计"在此按操作类型豁免（聚合统计、可由行级 updated_at 追溯），
  绑定/解绑等低频敏感写仍全部审计。
- **名字取服务端会话**：ModuleContext 向后兼容扩展 `displayName`（网关透传），
  不采信客户端昵称，防止伪造排名署名。

## 2. 决策二：统计放哪

两层：大屏放"今日听歌"迷你卡（紧凑、无数据自动隐藏），完整统计独立页
`/m/dashboard/listening`（dashboard 模块的路由，sidebar 与大屏"功能"入口均可达）。
统计是深读场景，不挤占大屏首屏信息密度。

## 3. 决策三：大屏主导（产品定位）

- **根路径 `/` 即大屏**：工作空间启用 dashboard 模块时，根路径直接渲染大屏，
  注册/登录落地即大屏；Shell 按"大屏页"处理根路径（隐藏顶栏、去内边距）。
- **架构不变**：大屏在架构上仍是模块（数据/权限/事件/迁移都走模块体系），
  改变的只是产品呈现——这是装配层（module-registry / app-shell）的编排结果，
  内核未被修改（仅 ModuleContext 向后兼容加字段）。
- **延伸入口**：大屏顶栏"功能"下拉列出其他已启用模块页面 + 听歌统计 + 通知/设置；
  旧"今天"页保留为未启用任何模块时的引导页。

## 4. 已知边界

- 排名在工作空间内成员互相可见（个人/团队系统语义，v1 接受；不做隐私开关）。
- 心跳依赖页面存活：极端情况（杀进程）丢失最近 ≤30 秒，可接受。
- 挂墙无人值守场景的播放统计同样依赖页面存活，与 ADR-0006 的 PWA 自动播放
  限制同源，后续以 PWA 一并解决。
