# ADR-0006：大屏音乐接入用户网易云账号（扫码登录 + 喜欢列表）

- 状态：已接受（用户于 2026-11-06 确认"按此方案做"）
- 日期：2026-11-07
- 关联：AGENTS.md §5（外部服务经适配器接口）；ADR-0005（模块协议）；roadmap 大屏音乐条目

## 1. 背景与目标

大屏播放器最初内置 19 首硬编码曲目（`TRACKS`），全是网易云允许网页外链的白名单歌曲——
不用登录就能播，但数量封顶、与用户无关。系统定位是多用户部署（各账号、各大屏、各计划），
音乐来源必须跟随"每个用户自己的网易云账号"。

目标：用户在播放器里触发网易云登录 → 获取其账号的"喜欢列表"作为曲目源 → 播放；
未绑定或接口失败时回退内置精选歌单，播放器永远可用。

## 2. 关键决策

### D1 登录方式：二维码扫码（不用密码、不贴 cookie）

网易云无官方开放 API，本功能基于社区逆向的非官方接口（可行性已于 2026-11-06 实测：
`/api/login/qrcode/unikey` 等，桌面客户端 UA + 明文表单即可直连，无需 weapi/eapi 加密）。
三种候选里选二维码：

- **扫码**（选定）：密码不经过本系统；体验与网易云官方网页一致；cookie 由服务端在
  轮询 confirmed 时直接从 Set-Cookie 获取。
- 手机号+密码：需实现其私有加密且密码会经过/落在本系统，风险与合规更差。
- 手工粘贴 cookie：无需轮询但体验差，仅保留为将来的兜底入口（未实现）。

### D2 凭据存储：AES-256-GCM 加密落库，fail-closed

网易云会话 cookie（含 `MUSIC_U`）等同账号凭据：

- 落库前用 AES-256-GCM 加密（`providers/secret-box.ts`），密钥从环境变量
  `ATLAS_NETEASE_SECRET`（≥16 字符）经 scrypt 派生；**未配置时绑定动作直接报错**，
  绝不明文落库。
- cookie 明文只在内存流转；不写日志、不进审计 payload、不进测试夹具（单测用假 token）。
- 解绑 = 软删除 + 密文字段覆写为 `unbound`（旧密文不可再查询）。
- 新表 `modules.dashboard.netease_binding`：`workspace_id + user_id` 唯一（部分唯一索引，
  软删后可重扫）、RLS 第二道防线、绑定/解绑发事件 `dashboard.netease.bound|unbound` 留痕。

### D3 接口封装：手写适配器，不引第三方网易云库

- 自写 `providers/netease.ts`（约 200 行）：二维码 key/轮询、账号信息、喜欢列表、
  歌曲元数据（500/批）、歌曲 CDN 地址。全部失败归一为 `NeteaseError`，上层兜底。
- 不引入 `NeteaseCloudMusicApi` 类社区包：其依赖树过重（数百传递依赖）且上游曾被
  DMCA 下架，供应链风险与宪法 §8 依赖纪律不符。协议细节（UA、type:3 等）已实测固化
  在适配器内并写注释；若未来协议漂移，只改这一个文件（宪法 §5 适配器可替换）。
- 二维码渲染用 `qrcode`（MIT，~50KB，浏览器本地 toDataURL）——**unikey 是一次性登录
  凭据，绝不能发给第三方二维码服务**，故必须本地渲染。

### D4 音频链路：浏览器直连 CDN，不代理

- 已绑定歌曲：服务端按需换取有时效的 CDN 地址（`neteaseSongUrl`，前端 staleTime 4 分钟），
  `<audio>` 直连网易 CDN，服务器零带宽成本。
- 地址取不到（VIP/版权限制）或播放失败：明确提示并可切歌，不伪造播放状态（沿用既有语义）。
- 未绑定回退：内置精选歌单走原有 outer/url 外链。

### D5 曲目源切换：绑定优先，内置兜底

`usingNetease = 绑定存在 && 喜欢列表非空`；`neteaseLiked` 的任何失败（风控/网络/凭据过期）
都让前端回退内置歌单，不阻塞播放器。切换来源时播放索引归零。

## 3. 风险与边界（如实记录）

1. **非官方接口**：网易可能随时调整或风控（同 IP 多用户请求尤其可能触发限流）。
   影响范围限于音乐功能，由回退内置歌单兜底；凭据过期（301）提示重新扫码。
2. **版权**：VIP/灰色歌曲能否播放取决于用户自己账号的权益，前端已明确降级提示。
3. **合规**：个人自用可行；**若将来对外售卖**，网易云音乐的非官方接入需重新评估
   （官方合作、许可或下架该功能），不得作为售卖卖点。
4. **多租户**：绑定按 (workspace, user) 隔离，用户在各工作空间需分别扫码（v1 接受，
   符合"每个租户独立配置"的售卖形态）。

## 4. 测试与验证

- 单测 12 个（`apps/api/test/dashboard-netease.spec.ts`）：加密盒往返/防篡改、二维码
  状态机（801/802/803/800/空响应）、cookie 提取缺 MUSIC_U 拒绝、喜欢列表保序、
  CDN 地址 null 透传。
- e2e 4 条：原黑胶播放器用例（未绑定回归）+ 新增绑定流用例（路由拦截：扫码弹窗 →
  waiting → confirmed → 喜欢列表播放 → 解绑回退内置歌单）。
- 真实扫码全链路（unikey 申请、轮询、cookie 落库、喜欢列表拉取）需用户用网易云 App
  扫码做一次人工验收。
