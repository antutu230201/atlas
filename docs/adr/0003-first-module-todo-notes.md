# ADR-0003：阶段 3 第一个真实模块 = 待办与笔记

- 状态：已接受
- 日期：2026-10-30
- 关联：总体设计文档第七节阶段 3；AGENTS.md §2

## 背景

阶段 3 要用"一个真实模块"同时验证模块协议与支撑日常使用。候选：待办与笔记（文档默认）、习惯打卡、目标与年度计划、复盘日记。

## 决策

用户于 2026-10-30 选定 **待办与笔记** 作为第一个真实模块（文档默认项）。

理由：

1. 增删改查、搜索、筛选、排序、批量操作、拖拽排序、撤销重做、回收站等能力全覆盖，是验证模块协议（manifest、权限点、事件、首页小组件、导入导出）最全面、风险最低的载体。
2. 它是其他成长类模块（习惯、目标、复盘）的通用底座 —— 这些模块将来都以"事件订阅"方式与它联动，而非互相引用（架构铁律）。

## 后果

- 阶段 3 需求说明按文档模板产出（用户故事 / 数据模型 / 界面草图 / 权限点 / 事件 / 小组件 / AI 工具 / 导入导出格式），确认后实现。
- 内核设计（阶段 2）不需要为该模块做特殊化，但事件类型命名要预留 `todo.*` / `note.*` 命名空间。
- 习惯打卡、目标、复盘日记进入 `docs/ideas.md` 候选池，待首模块验收后排期。
