# 目标（OKR）使用手册

目标模块回答一个问题：**日常的待办和习惯，指向哪里？**

用它定一个让自己心跳加速的方向（目标），再拆成 1–3 条可度量的关键结果，每天看一眼进度。

## 入口

侧边栏「目标」，或直接访问 `/m/goals/list`。首次使用需在 设置 → 模块 中启用「目标」。

## 创建目标

1. 页面底部「新建目标」表单：填标题（如「2026 身体重塑」）、选图标、写一句为什么。
2. 周期四选一：
   - **年度**：自动取今年 1/1 – 12/31
   - **季度**：自动取本季度首末
   - **月度**：自动取本月首末
   - **自定义**：手选起止日期
3. 创建后卡片立即出现在列表顶部区域，进度从 0% 开始。

## 关键结果（让目标可度量）

目标卡内点「＋ 添加关键结果」，两种类型：

- **数值型**：从 X 到 Y。支持反向目标（如体重从 75kg 减到 70kg）。更新进度两种方式：
  - 行内 ± 按钮步进（步长 = 区间 / 10）
  - 直接输入当前值，回车或点其他位置提交
- **达成型**：完成 / 未完成两态，点「标记达成」即 100%。

目标总进度 = 各关键结果进度的平均值；全部达成时卡片显示「已达成 ✓」。

## 日常用法建议

- 顶部概览卡实时汇总：平均进度、已达成关键结果 x/y、全部达成目标数。
- 完成的目标可以「归档」收起来（数据保留，可随时恢复）。
- 数值回落（比如体重反弹）进度会自动回退，达成标记同步撤销——不粉饰太平。

## 常见问题

- **关键结果想换类型？** 类型不可直接改（进度语义不同），删除后重新添加。
- **删除关键结果会丢数据吗？** 软删除，数据保留在库中；恢复目标不会连带复活已删的关键结果。
- **周期选错了？** 归档后重建，或在目标卡上重新编辑周期。
