# 复盘（日记 / 周报）使用手册

复盘模块回答一个问题：**这段日子过得怎么样？** 待办管执行、习惯管坚持、目标管方向——复盘把它们串成完整的成长闭环。

## 入口

侧边栏「复盘」，或 `/m/journal/review`。首次使用需在 设置 → 模块 中启用「复盘」。

## 日记（每天一篇）

1. 选一个心情（😞 → 😄 五档）
2. 按模板写几行：今天的三件好事 / 卡住的地方 / 明天最重要的一件事
3. 保存。同一天再保存就是修改（一篇日记），不会重复

顶部「连续复盘天数」会自动累计——今天还没写不断签，从昨天起算。

## 周复盘（一周一篇，从周一起算）

1. 点「生成本地草稿」——系统自动汇总本周真实数据（完成的待办、习惯打卡、目标进度），生成一份可编辑的底稿
2. 在底稿上补上「做得好的 / 可以更好的 / 下周专注的一件事」
3. 保存。周报与日记互不影响（同一天可以同时有日记和周报）

## AI 润色（可选、显式）

写完一段后，编辑器会出现「✦ AI 润色」按钮：

- 点击后 AI 把原文整理得更通顺（100 字以内），**原文不动**，润色稿存在下方供参考
- 每次点击消耗一次 AI 调用；AI 失败会明确提示，不会静默吞掉
- 未配置 AI 供应商（本地预览模式）时按钮会明确拒绝，不产生任何费用
- 修改正文后，旧润色稿自动清除（避免与新原文不符）

## 月列表与归档

- 概览卡用 ← → 切换月份，查看历史复盘
- 点列表条目可载入编辑器继续修改
- 「删除本条」软删除进归档区，可随时恢复；若同日期已写了新条目，恢复会提示先删新条目

## 常见问题

- **周复盘的日期？** 以周一为锚点（11/9 – 11/15 这样的周期），只能保存在周一。
- **润色稿会被覆盖吗？** 不会——原文永远是你写的，润色稿只是参考。
- **AI 润色收费吗？** 每次点击调用一次 AI（走你配置的供应商）；不点就不花一分钱。

## 模板设置（自定义写作提示）

复盘页右侧「模板设置」按钮：

- **日记模板 / 周复盘模板**：自定义写作占位提示与「写今天 / 写本周」的预填内容
- 留空保存即恢复默认模板
- 模板为工作空间级设置，对所有成员生效
