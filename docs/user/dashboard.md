# 个人大屏使用指南

> 大屏是 Atlas 的首页（登录后默认进入）。设计目标：一眼看清「今天」，挂墙时是一块安静的生活仪表盘。

## 顶栏按钮

| 按钮   | 作用                                                                                      |
| ------ | ----------------------------------------------------------------------------------------- |
| 功能   | 延伸功能菜单：AI 助手、听歌统计                                                           |
| 铃铛   | 通知中心（带未读数角标，5 分钟刷新）                                                      |
| 亮/暗  | 大屏主题（跟随系统）                                                                      |
| 专注   | **专注模式**：隐藏热榜、每日小结、打卡与滚动条，只留时钟/天气/待办/倒计时（再点一次恢复） |
| 低功耗 | 关闭壁纸与持续动画，性能弱或远程投屏时用                                                  |
| 刷新   | 立即重新拉取全部数据源                                                                    |
| 设置   | 大屏设置抽屉（见下）                                                                      |
| 全屏   | 浏览器全屏（挂墙推荐）                                                                    |

顶栏「同步 HH:MM」显示最近一次数据拉取时间，点击它同样可以刷新。

## 键盘快捷键

按键在大屏页（不在任何输入框里）生效：

| 按键 | 作用            |
| ---- | --------------- |
| `F`  | 进入 / 退出全屏 |
| `C`  | 切换专注模式    |
| `L`  | 切换低功耗      |
| `R`  | 刷新全部数据源  |
| `S`  | 打开设置抽屉    |
| `A`  | 打开 AI 助手    |
| `?`  | 显示快捷键列表  |

## 时钟卡

- 数字格：**今日完成**（待办完成驱动打卡数）、**待办**（剩余件数，点击进待办页）、**连续打卡**、**期待**（最近一个未来纪念日的剩余天数，点击到倒计时区）
- 农历日期可点击，跳转万年历查看干支宜忌
- AI 每日小结按天生成（约 6 小时刷新一次），卡片右上有「重写」可立即重新生成

## 音乐播放器

- 播放器跨页面保留。滚动大屏或听歌统计页时会淡出并暂时停止响应点击，停滚后自动恢复，避免挡住内容。

## 热榜与稍后读

- 三源：微博 / 抖音 / B 站，5 分钟自动刷新
- **关注词**（设置里配置）：命中的标题会紫色高亮，标题旁出现「关注 N」计数
- **稍后读**：鼠标悬停热榜条目，行尾点「＋」收藏；标题旁「稍后读 N」徽章打开面板——点击条目即打开网页并自动移除，也可置顶、删除、复制全部。收藏 7 天后自动过期，数据只存本机

## 倒计时与纪念日

- 支持公历与**农历**：勾选「农历」后选农历月/日（含闰月），系统自动换算为下一次发生的公历日期
- 勾选「每年循环」：日期过期后自动顺推到下一年（闰月会跳到下一个有该闰月的年份）
- 点击卡片任意空白处即可编辑；标题旁「↻」表示每年循环

## 日报与周报（自动推送到通知中心）

- **每日 23:00**：「今日回顾」——当天完成的待办、听歌时长与打卡汇总（当天没有任何活动则不打扰），附带 AI 晚安语
- **每周一**：「听歌周报」——上周听歌时长、全站排名与最常听歌曲，附带 AI 一句话点评

## 设置抽屉

- 天气城市（定位或搜索）
- 各数据源开关（关掉的源不再抓取）
- **关注词**（最多 20 个，命中的热榜标题高亮）
- 壁纸开关
- **护屏**：防烧屏微位移（每 90 秒在 3px 内移动）与夜间自动压暗（22:00–07:00）——这两个设置只对当前设备生效

## 常见问题

- **数据不同步？** 按 `R` 或点顶栏同步时间手动刷新；检查设置里对应源是否被关掉。
- **AI 小结显示「PREVIEW · 待接入」？** AI 供应商未配置（设置里没有可用的 API Key），配置后点「重写」立即生成。
- **页面白屏或接口无响应（开发环境）？** 运行 `node .local/tools/check-dev.mjs --fix` 后重新 `pnpm dev`。
