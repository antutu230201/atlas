# 应用页面无障碍审计（2026-11-08）

**范围：**真实应用路由，而非 Storybook 组件。已自动化部分可重复执行；无法自动化的项目单独列出，未标记为验收通过。

## 方法

- 引擎：`axe-core` 4.14.0（与 `pnpm a11y` 的 Storybook 门禁同版本，MIT/MPL-2.0），仅作 `@atlas/web` 的 devDependency，运行时由 `addScriptTag` 注入，不进入生产包。
- 用例：`apps/web/e2e/a11y.spec.ts`，WCAG 2.1 A/AA 规则，只断言 `serious` / `critical`。
- 组合：11 条路由 × 亮/暗 × 1280/390，共 44 次扫描；每条路由只导航一次，主题与视口原地切换。
- 稳定性：等待骨架屏与按钮 loading 结束再扫描（避免把过渡态 50% 透明按钮误判为对比度缺陷）；遇首启引导等模态先关闭；单条路由 15s 未就绪记为跳过，不拖死用例。
- 命令：`E2E_API_PORT=3011 E2E_WEB_PORT=3010 pnpm --filter @atlas/web exec playwright test e2e/a11y.spec.ts`（复用服务时可用 `.local/playwright.e2e.config.ts`，约 50s）。

## 本轮发现并修复

| 位置                   | 问题                                                                                              | 严重度   | 修复                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------- |
| 全站外壳搜索按钮       | `aria-label="打开命令面板"` 与可见文字「搜索 Ctrl+K」不一致（WCAG 2.5.3，语音控制无法按名称点击） | serious  | 去掉 `aria-label`，名称取自可见文字；快捷键改用 `aria-keyshortcuts="Control+K"` |
| 待办排序按钮           | `aria-label="切换为升序"` 与可见文字「↓ 降序」不一致                                              | serious  | 名称改为「当前降序，切换为升序」，箭头 `aria-hidden`                            |
| 悬浮播放器展开按钮     | `aria-label` 覆盖了含艺人/进度的可见文字                                                          | serious  | 去掉 `aria-label`，补 `sr-only` 动作说明，名称包含全部可见文字                  |
| 大屏刷新/设置图标按钮  | 390px 下文字被隐藏后无可访问名称                                                                  | critical | 补 `aria-label` 与 `title`（「刷新大屏数据」「大屏设置」）                      |
| 大屏滚动头条第二份拷贝 | `aria-hidden` 容器内仍有可聚焦链接                                                                | serious  | 第二份拷贝的链接 `tabIndex={-1}`                                                |
| 大屏数据源状态点       | `<span>` 直接使用 `aria-label`（ARIA 不允许）                                                     | serious  | 改为 `role="img"`                                                               |
| 大屏汇总卡「重写」按钮 | 名称「重新生成每日小结」不含可见文字「重写」                                                      | serious  | 去掉 `aria-label`，补 `sr-only` 每日小结                                        |
| 大屏听歌小卡片         | 链接 `aria-label` 与卡片内可见文字不一致                                                          | serious  | 去掉 `aria-label`，名称取自内容                                                 |
| 大屏设置抽屉提示       | `text-muted/80`、`/60` 在 11px 下对比度不足                                                       | serious  | 改为不透明 `text-muted`                                                         |
| 设置页审计表格         | 横向滚动容器不可键盘聚焦（WCAG 2.1.1）                                                            | serious  | `Table` 组件滚动容器补 `tabIndex={0}` + `role="region"` + 名称                  |
| 播放器副标题           | 浅色面板上 `text-muted` 对比度 4.08:1                                                             | serious  | 改为 `text-text/75`（>5.9:1）                                                   |
